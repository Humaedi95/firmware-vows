A single wedding vow, spoken by a robot at its own wedding — funny, tender,
and unmistakably machine. One sentence, under 200 characters, written to
`/output/entry.txt`.

Entry for the make.fun bounty
[Till Firmware Do Us Part](https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929).

## Run

```sh
python3 main.py
```

This writes the vow to `/output/entry.txt`.
